# Master Share Trading System

Pine Script indicators and screeners for **Bursa Malaysia (KLSE)**, built for TradingView.

## Tools

### Intraday Sniper (Long) + PD Levels
- **Timeframe:** 5-minute
- **Exchange:** KLSE
- Entry signals gated by Previous Day High/Low/Close levels, EMA, VWAP, and volume surge. ATR-based SL/TP locked at entry. Includes a live HUD table showing signal state, PD zone, and SL/TP values.
- Latest: `V7 Intraday Sniper (Long) + PD Levels`

### KLSE Momentum Swing Screener
- Swing trade screener for KLSE-listed stocks.
- Latest: `KLSE Momentum Swing Screener-v5`

### Minervini VCP + SmartMCDX Backtest
- Backtests the Minervini Volatility Contraction Pattern (VCP) combined with SmartMCDX signals.
- Includes a dashboard view for KLSE.
- Latest: `Minervini VCP + SmartMCDX Backtest-v8-KLSE.txt`

### Pro Quant Desk (KLSE) + True RS + Heat
- Quantitative desk tool with True Relative Strength and heat scoring for KLSE stocks.
- Latest: `Pro Quant Desk (KLSE) + True RS + Heat- v7`

## Usage

Each file contains a self-contained Pine Script. To use:
1. Open [TradingView](https://www.tradingview.com) and go to the Pine Script editor.
2. Paste the contents of the desired file.
3. Click **Add to chart**.

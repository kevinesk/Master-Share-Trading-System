## Quick Reference

### Daily Pre-Market Checklist
- [ ] Check KLCI futures (if available) or overnight US market direction
- [ ] Check USD/MYR for foreign flow signals
- [ ] Read Bursa announcements for held stocks
- [ ] Run KLSE Screener to get today's T1/T2 list
- [ ] Run News Filter to catch any sentiment shifts
- [ ] Identify 2–3 highest-conviction setups from T1 list
- [ ] Set price alerts on TradingView for pivot levels

### Trade Entry Checklist (Every Trade)
- [ ] Macro favourable (KLCI > EMA50, Dow > EMA20)?
- [ ] Stock in Stage 2 (Trend Template ✓)?
- [ ] VCP or valid base setup identified?
- [ ] Breakout on volume (≥1.5× average)?
- [ ] Entry within 2–3% of pivot?
- [ ] Stop loss defined (below last VCP low)?
- [ ] Position size calculated (max 2% portfolio risk)?
- [ ] Risk:reward ≥ 1:2?

### Trade Exit Checklist
- [ ] Is the original thesis (Stage 2 + VCP) still intact?
- [ ] Has stock closed below EMA50 on heavy volume?
- [ ] Is there a sector/macro regime change?
- [ ] Has gain reached +20%? Consider partial exit.
- [ ] Has drawdown hit –7%? Hard stop — exit.

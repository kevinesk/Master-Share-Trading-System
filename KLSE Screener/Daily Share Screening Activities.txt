## 2. Screener 1 — K2 AI Robot with VCP Scan (Weekend)

### Current Issues

| Filter | Issue |
|---|---|
| Vol below Avg 30D by **70% or more** | Too aggressive — eliminates most valid KLSE VCP setups. KLSE contraction = 30–50% below avg |
| Missing SMA(150) > SMA(200) | Minervini **C2** — critical alignment check not in screener |
| Missing near 52W High | Minervini **C7** requires price > 75% of 52W High — missing entirely |
| Missing RS vs KLCI | Strategy requires stock outperforming FBMKLCI — no proxy in screener |
| Mkt cap > 300M | Eliminates valid KLSE mid-cap VCP setups — lower to 150M |
| "Price above EMA(20) by 0–3%" | Uses EMA(20) — strategy uses EMA(21). Minor but align where possible |
| No MCDX / smart money proxy | No RSI+MFI bullish zone filter to approximate banker accumulation |

### Improved Filter Set

```
Market: MY (Malaysia)
━━━ MINERVINI TREND TEMPLATE (C1–C7) ━━━
✅ Price > SMA(150)                     ← C1 partial
✅ Price > SMA(200)                     ← C1 partial
✅ SMA(50) > SMA(150)                   ← C4
✅ SMA(50) > SMA(200)                   ← C4
✅ SMA(150) > SMA(200)     ← ADD THIS   ← C2 (was missing)
✅ Price > EMA(50)                      ← C5
✅ SMA(20) 1W > SMA(50) 1W             ← weekly trend
✅ New High (52W)          ← REPLACE "High" with this  ← C7 proxy

━━━ VCP SQUEEZE CONDITIONS ━━━
✅ Price above EMA(21) by 0% to 3%     ← tight coil

   (volume contraction, not extreme dryup)

━━━ KLSE QUALITY GATES ━━━
```

## 5. Screener 4 — Intraday Scan (9:30am / 11:00am / 2:00pm)

### Current Issues

| Filter | Issue |
|---|---|
| Vol chg > 200% | Too aggressive — valid breakout bars often show 100–150%. Lower to 100% |
| Avg vol 30D > 1M | ✅ Correct — high liquidity needed for 5m execution |
| Rel vol at time > 2 | ✅ Perfect — real-time volume confirmation |
| Chg > 1.5% | ✅ Good — filters out flat/choppy stocks |
| VWAP < Price | ✅ Perfect — direct Intraday Sniper alignment |
| RSI(14) 55–70 | ✅ Good — bullish but not overbought |
| EMA(20) > EMA(50) | ✅ Good — intraday trend aligned |
| Missing EMA(9) > EMA(20) | No short-term momentum crossover check |
| Missing PDH breakout | Price above Previous Day High = key Intraday Sniper gate |
| Gap % undefined | Should be Gap % > 0 (positive gap signals strength) |

### Improved Filter Set

```
Market: MY (Malaysia)
━━━ INTRADAY MOMENTUM GATES ━━━
✅ Price > 0.50 MYR                    ← keep
✅ Avg vol 30D > 1M                    ← keep (intraday liquidity)
✅ Rel vol at time > 2                 ← keep (volume surge NOW)
✅ Chg > 1.5%                          ← keep (positive day)
✅ Gap % > 0                ← DEFINE   ← gapping up stocks maintain momentum
✅ Vol chg > 100%           ← CHANGE from 200% → 100%

━━━ INTRADAY SNIPER ALIGNMENT ━━━
✅ VWAP < Price                        ← keep ✓ (exact Sniper condition)
✅ RSI(14) 55 to 70                    ← keep
✅ EMA(20) > EMA(50)                   ← keep
✅ EMA(9) > EMA(20)         ← ADD      ← fast momentum crossover

━━━ DAILY TREND ANCHOR ━━━
✅ Price > EMA(50)          ← ADD      ← daily trend backing
✅ SMA(50) > SMA(200)       ← ADD      ← golden cross confirmation
```

> **3 Scan Windows vs KLSE Session:**
> - **9:30am** — Post opening noise (Sniper filters 9:00–9:30 as noise) ✅ Best window
> - **11:00am** — Peak morning momentum ✅ Good
> - **2:00pm** — Post-lunch open (Bursa afternoon session resumes ~2:30pm) ⚠️ Shift to **2:30pm** to avoid the lunch dead zone
